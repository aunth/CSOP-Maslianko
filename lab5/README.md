# Практична робота №5 - Робота з сервісами та Angular компонентами

## Опис

Застосунок для роботи з API randomuser.me, який:
- Отримує список користувачів з API
- Відображає їх у вигляді таблиці
- Показує детальну інформацію в модальному вікні при кліку на рядок
- Дозволяє додавати користувачів до вибраних
- Відображає вибрані елементи в окремому компоненті

## Варіант

**Варіант 1**: Використовуючи API https://randomuser.me виведіть інформацію про користувачів системи (Ім'я, email, логін, пароль, контактний телефон).

## Технології

- Angular 20
- TypeScript
- Axios (для HTTP запитів)
- Chart.js / ng2-charts (для графіків - опціонально)
- RxJS (для реактивного програмування)

## Функціональність

### 1. Таблиця користувачів (`UsersTable`)
- Завантажує користувачів з API
- Відображає: фото, ім'я, email, логін, пароль, телефон
- Клік на рядок відкриває модальне вікно
- Кнопка зірочки для додавання до вибраних

### 2. Модальне вікно (`UserDetailModal`)
- Показує повну інформацію про користувача
- Велике фото
- Всі деталі: email, логін, пароль, телефони, адреса, дата народження
- Можливість додати/видалити з вибраних

### 3. Список вибраних (`FavoritesList`)
- Відображає всіх вибраних користувачів
- Картки з фото та основною інформацією
- Можливість видалити з вибраних
- Збереження в localStorage

## Запуск

```bash
# З кореня проекту
npm run lab5

# Або з папки lab5
cd lab5
npm start
```

Додаток буде доступний на `http://localhost:4200`

## API

Використовується API: https://randomuser.me/api

### Приклад запиту:
```
GET https://randomuser.me/api/?results=20
```

## Особливості реалізації

1. **Axios** - використовується для HTTP запитів замість стандартного HttpClient
2. **RxJS** - для реактивного управління станом вибраних елементів
3. **localStorage** - для збереження вибраних елементів між сесіями
4. **Standalone компоненти** - сучасний підхід Angular
5. **Responsive дизайн** - адаптивна верстка

## Додаткові можливості (для максимального балу)

- ✅ Використання axios для HTTP запитів
- ⚠️ Графічна бібліотека (Chart.js встановлена, але не використовується в UI)
  - Можна додати графік розподілу користувачів за країнами або віком
